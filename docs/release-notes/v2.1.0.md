# TimesCam v2.1.0 · 原生画质 + 相机稳定性

发布日期：2026-11-24

本次只更新**手机端**，上位机仍是 v1.1.0，无需重新下载 exe。

## 这次的改动

### 画质接近原生相机

- 默认画质从「4K」改成「原生最高」：直接取相机传感器的最大分辨率，相机直出，不再二次压缩。
- 旋转照片时的 JPEG 重编码质量从 92 提到 98，画质损失降到最低；不旋转时走相机原始字节，零损失。
- 从系统相册选图不再传 `imageQuality`，直接读原图字节。
- 点按对焦时联动曝光测光（点哪测哪），和原生相机行为一致，避免主体忽明忽暗。

### 修复相机黑屏卡死

- 修复息屏 / 切 App / 相机被系统回收后，回到相机页一直黑屏转圈、只能拍一次的问题。
- 相机启动请求不再被丢弃：启动或拍照期间被切走，操作结束后自动补上重启。
- `initialize()` 加 8 秒超时，相机被别的 App 占住时不再无限转圈。
- 黑屏时点一下预览区域即可手动重连，不用退出重进。
- 旧相机控制器 dispose 加保护，避免双重释放。

## 已知情况

- 「原生最高」在 4800 万 / 一亿像素机型上，配合旋转功能解码会比较重；如感觉卡顿，可在设置里切回「4K」。
- 系统相机的厂商算法（HDR、夜景多帧、AI 美化）属于相机 HAL 专有能力，本版无法复现。
- 协议不变，仍是局域网直传协议 v1，和 v1.1.x 上位机完全兼容。
