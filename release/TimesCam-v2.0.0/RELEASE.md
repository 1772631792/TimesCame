# TimesCam v2.0.0 · 画面旋转 + 补光灯

发布日期：2026-11-20

本次只更新**手机端**，上位机仍是 v1.1.0，无需重新下载 exe。

## 这次的改动

### 画面顺时针旋转 90°

- 相机页右上角按钮：点一下画面**顺时针转 90°**，预览和拍下来的照片一起转，连点四次转回原位。
- 角度本地保存，下次进相机页还是上次的角度。
- 旋转在后台 isolate 里做，4K 图也不会卡住取景；保留本地副本时，本地文件也是转好的方向。
- 转过来之后点击对焦照样准（对焦点会换算回传感器坐标）。

### 补光灯（常亮手电筒）

- 相机页按钮从「拍照闪光」改成 **开灯 / 关灯**：暗处取景、拍板书、拍实物都更稳。
- 开着灯拍照不会闪一下再灭，拍完继续亮，直到你自己关掉。
- 状态本地保存，下次进相机页还是你上次的选择。
- 没有闪光灯的机型点了会提示「这颗镜头没有补光灯」，并把开关复位，不会卡在错误状态。

### 相机页按钮点不动、返回不了首页

- 顶部一整行被 Stack 拉满高度，按钮被挤到屏幕中间，容易点空；现在固定贴顶。
- 拍照白闪遮罩在透明状态下仍然吃点击，把顶部按钮全挡住了；现在遮罩不再接收点击。
- 按钮放大：顶部 42 → **54**，底部两侧 54 → **62**。
- 安卓返回手势：相机页 / 相册页按返回先回首页，不会直接退出 App。

### 其他

- 版本号：手机端 `2.0.0+6`，上位机 `1.1.0`。
- 协议不变，仍是局域网直传协议 v1，和 v1.1.x 上位机完全兼容。

## 已知情况

- 补光灯依赖相机硬件，模拟器上不可用。
- 旋转只作用于相机页拍的照片；从系统相册选的图片保持原方向。
- 这一版去掉了前后摄切换入口，只用后摄。
