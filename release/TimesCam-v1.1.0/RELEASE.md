# TimesCam v1.1.0 · 同类多选

发布日期：2026-11-20

## 这次的改动

### 一个 WiFi 里有多台电脑时，头像选谁

- 手机端发现电脑后会先汇总 **0.5 秒**：
  - **只有一台** → 直接连上，不用点任何按钮（和以前一样快）。
  - **不止一台** → 首页列出每台电脑的**渐变色头像** + 名字 + 地址 + 已存张数，点一下就连接。
- 每台电脑的身份（`id`）写在它自己的配置里，头像色相由 id 决定，**同一台电脑永远同一个颜色**。
- 连过一次就会记住：下次那台电脑一出现，**立刻直连**，不再弹选择。
- 设置里能看到「记住的电脑」，随时可以「忘记」。
- 已连接状态新增「切换」，一键回到多选列表。

### 上位机：在线手机头像 + 只看这台

- 左侧「连接」卡片新增**在线手机列表**：头像、名字、已收张数、IP。
- 有多台手机时，点某一行 → **照片墙只显示这台手机的照片**，右上角计数变成 `2 / 6 张`；点「看全部」恢复。
- 手机掉线后自动取消筛选，不会卡在空列表。
- 状态栏改成「已连接 · 3 台手机」，单台时仍显示手机名。

### 其他

- 发现协议新增 `id` / `hue` 字段（`/info` 同步返回），老版本 App 仍能连；老版本上位机没有这两个字段时手机会退回用地址识别。
- 版本号：手机端 `1.1.0+2`，上位机 `1.1.0`。
